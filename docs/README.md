## 阅读这些记录时

- 插件版本、MCP 协议日期、Affinity 应用构建号是三个不同维度。当前仓库清单为插件 `0.5.4-dev.2`，版本格式和实际交付状态分别核对；已记录的应用样本包括 2026-10-08 的 `3.3.0.4850 Win32` 与 2026-10-19～2026-10-22 的 `3.3.1.4940 MacOS`，后者覆盖注明的批量、查询、撤销、矩形/海报预览、单行文字光学对齐、双框文本流、异步关闭及已有路径画笔用例。它们不等于“官方最新版”。具体来源见[版本身份表](sdk/README.md#version-identity)。
- SDK 能力以具体操作、对象和后置状态为单位。函数存在、调用无异常、文本正确、视觉正确与文件保存成功分别需要证据。
- 操作配方默认跨系统共用，实测平台只标明证据环境；没有其它系统的单独测试，不构成拒绝操作的理由。系统差异需有依据，见[表述约束](maintaining.md#capability-platform-wording)。
- [光学对齐样本](sdk/3.3.1.4940-macos.md#optical-alignment)区分可通过 SDK 设置的模式、已查未找到的自定义规则入口，以及界面编辑后的实际效果；对象边界对齐不等于中文主体对齐。
- [文本流与异步关闭样本](sdk/3.3.1.4940-macos.md#linked-text-flow-and-close)明确取消链接后全文留在源框、目标框变空，以及异步关闭直接丢弃未保存内容；不把取消链接当作撤销链接，也不依赖保存提示保护用户工作。
- [SDK入口与行为补测](sdk/3.3.1.4940-macos.md#sdk-availability)区分4,260个函数入口与实际成功样本：普通字符插入、四种布尔、值/像素、五种同步导出、异步PNG及保存重开仅在注明范围通过；异步复制、两个尺寸反例、默认笔刷和未验证项仍保留。异步PNG成功不能推导全部异步API成功。
- [已有路径画笔补测](sdk/3.3.1.4940-macos.md#existing-path-brush)验证了界面准备真实源笔触后，SDK 的读取、独立克隆、改宽、复用和历史恢复；单字段掩码生效，不把默认工厂、RasterBrush 或预设枚举一并标为可用。
- [导出、保存与复杂文本扩展](sdk/3.3.1.4940-macos.md#layout-export-save)记录两页/选页与透明混排导出、异步保存覆盖重开、三框跨 spread 排文和已知高度重排；明确链首断链清空、混排替换丢格式、默认出血范围不足及资源包离线失真反例。界面转换不算 SDK 转换，包能打开不等于原图可用。
- 版本页中的“样本通过”指该页注明日期的既有实验；[脱敏证据摘要](sdk/evidence/2026-10-08.md)的结论只适用于记录的样本与观察日期。
- 随包 [Skill](../skills/affinity-mcp/SKILL.md) 和 [SDK reference](../skills/affinity-mcp/references/sdk-verified.md#version-boundaries) 区分历史记录与3.3样本，未注明新证据的旧案例需在目标构建复验。仓库内容更新不证明已安装副本或实时 preamble 已刷新。
