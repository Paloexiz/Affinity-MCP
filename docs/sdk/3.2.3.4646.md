## 历史能力目录

下表中的“有结果”只指原记录覆盖的具体案例，不是模块级保证。目标构建或对象不在记录范围内时，按[复验方法](verification.md)补测。

| 功能域 | 原记录中的有效案例 | 不能扩展成什么保证 | 来源 |
| --- | --- | --- | --- |
| 文档与生命周期 | 枚举文档、保存状态、新建多 spread、切页、undo/redo | 不证明向现有文档插页、所有关闭路径或任意撤销次数都可靠 | [Skill](../../skills/affinity-mcp/SKILL.md) |
| 节点创建与移动 | `AddChildNodesCommandBuilder` / `command.newNodes`；move/transform 读回 | `Document.addNode()` 不返回 newNodes；普通形状不是画板 | [SDK reference](../../skills/affinity-mcp/references/sdk-verified.md) |
| 文字和格式 | StoryBuilder 创建框文本、显式文本子选区替换、指定字体/字号/字距/对齐/缩进并读回 | 不证明无损混排转换、全部特殊 glyph 或链接框 | [SDK reference](../../skills/affinity-mcp/references/sdk-verified.md) |
| 页面与画板 | TopLeft 锚点、`reflowPages=false` 时改尺寸并读回 extents；真实画板 margin 读回 | 不证明 Layout 页的原生 margin/bleed 全部可读；删除画板不会自动恢复 spread 尺寸 | [SDK reference](../../skills/affinity-mcp/references/sdk-verified.md)、[几何参考](../../skills/affinity-mcp/references/page-geometry.md) |
| 像素与图像 | Bitmap / PixelBuffer 读写、兼容 buffer、图像资源与 raster bounds | 不能把原始像素域、内容界和放置尺寸混为一谈 | [SDK reference](../../skills/affinity-mcp/references/sdk-verified.md) |
| 填充与描边 | 实色、两段线性渐变、hatch、线宽和已有 vector brush | 不证明默认 brush 工厂、全部笔刷或透明度行为 | [SDK reference](../../skills/affinity-mcp/references/sdk-verified.md) |
| 选区与图像处理 | 指定矩形 raster 选区、外阴影/Multiply/gamma、部分滤镜字段、image trace 输出 PolyCurve | 不证明所有 mask 组合、全部 effect/filter 参数 | [SDK reference](../../skills/affinity-mcp/references/sdk-verified.md) |
| 保存和导出 | save/saveAs 的同步与异步路径；PNG CurrentSpread/CurrentPage；package IncludeImages；已有宏导出 | 不证明 PDF、所有格式/预设、出血、多页导出或宏录制/回放 | [SDK reference](../../skills/affinity-mcp/references/sdk-verified.md) |
| Slice export | 对已有 slice 取得 ExportConfig，改 size/format 后写回应用 | 不证明从零创建 slice/config，也不证明用这个 config 能直接完成导出 | [SDK reference](../../skills/affinity-mcp/references/sdk-verified.md) |
| 嵌入文档与图片框 | 读取嵌入元数据、切换有效 page/artboard ID；读取既有图片框 | 不证明 SDK 能创建/替换图片框内容；空 artboard ID 写入会失败 | [SDK reference](../../skills/affinity-mcp/references/sdk-verified.md) |
| 文件、网络与脚本库 | 桌面同步文件操作、部分异步读、同步本地 HTTP GET、timers、脚本库读写 | 不证明全盘权限、公网/TLS/异步网络或所有异步文件方法 | [SDK reference](../../skills/affinity-mcp/references/sdk-verified.md) |
| Dialog | 指定交互和回调结果 | MCP 超时不能证明对话框已消失或执行已结束 | [SDK reference](../../skills/affinity-mcp/references/sdk-verified.md) |

<a id="limits"></a>
## 历史限制与适用边界

| 入口/目标 | 历史记录 | 使用边界 |
| --- | --- | --- |
| `Document.close()`、`closeAsync()`、promises close | Windows 路径历史上返回 `NOT_IMPLEMENTED`；promises 转发到同一后端 | [后续同步样本](3.3.0.4850.md#lifecycle)和[异步关闭样本](3.3.1.4940-macos.md#linked-text-flow-and-close)分别记录；旧结果不是系统禁用条件。主题入口：[Skill](../../skills/affinity-mcp/SKILL.md) |
| `Node.setText` wrapper | convenience wrapper 引用了缺失的 `TextSelection.from`；显式子选区替换有示例 | 按目标构建查 [wrapper 与替换结果](3.3.0.4850.md#text)，不要把这条记录当作所有构建的限制。主题入口：[reference](../../skills/affinity-mcp/references/sdk-verified.md)及[脱敏证据摘要](evidence/2026-10-08.md#a-02) |
| `createInsertGlyph(..., CharGlyph.create(33))` | 历史构造失败：`expected GlyphHandle` | [后续普通字符样本](evidence/2026-10-21-sdk-availability.md#f-04)已经通过；旧记录保留，但它不是当前的通用限制 |
| 默认笔刷 | `VectorBrush.createDefault()` 历史上抛错；没有取得可用的 RasterBrush 对象 | 现在叫 PathBrush；默认工厂占位和已有实例获取的边界见[后续样本](evidence/2026-10-21-sdk-availability.md#f-05)，不能继续拿旧字段当回退方案 |
| `ExportScale.createWithWidthHeight(600, 800)` | 读回为 Square、multiplier 600、size 800 | [后续样本](evidence/2026-10-21-sdk-availability.md#f-05)重现了语义反例；工厂名不是宽高设置配方，也不能据此推定系统差异 |
| `FileSystemPromises.copyFile` | 返回 `NO_ENVIRONMENT`；其他指定异步读可用 | 按方法分别记录。来源：[reference](../../skills/affinity-mcp/references/sdk-verified.md) |
| `Document.generateImage` | 构造阶段 `PERMISSION_DENIED` | 一次拒绝不等于平台没有 AI；不要自动重试可能付费的操作。来源：[reference](../../skills/affinity-mcp/references/sdk-verified.md) |
| 现有文档插页、Boolean 全组合、复杂选区、更多导出选项 | 没有找到可用入口，或验证不足 | 保持原来的区分，不要合并成“全部不支持”。主题入口：[README](../../README.md#unsupported-or-unverified-features)；历史来源见上面的固定提交 |
