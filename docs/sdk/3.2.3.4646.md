需要恢复旧结论原貌时，可查[固定提交的 SDK reference](https://github.com/Paloexiz/Affinity-MCP/blob/b399cf64bf599a207308a7158fe8a1370658a209/skills/affinity-mcp/references/sdk-verified.md)与[固定提交的 Skill](https://github.com/Paloexiz/Affinity-MCP/blob/b399cf64bf599a207308a7158fe8a1370658a209/skills/affinity-mcp/SKILL.md)。当前构建差异见 [3.3.0.4850 记录](3.3.0.4850.md)和[脱敏证据摘要](evidence/2026-10-08.md)。

<a id="limits"></a>
## 历史限制及后续变化

| 入口/目标 | 历史记录 | 后续处理 |
| --- | --- | --- |
| `Document.close()`、`closeAsync()`、promises close | Windows 路径返回 `NOT_IMPLEMENTED`；promises 转发至同一后端 | [3.3 同步 close 样本已通过](3.3.0.4850.md#lifecycle)；异步未复验，不能继续笼统禁止所有 Windows close。来源：[旧 Skill](../../skills/affinity-mcp/SKILL.md) |
| `Node.setText` 的旧 wrapper | convenience wrapper 引用缺失的 `TextSelection.from`；显式子选区替换有示例 | [3.3 wrapper 和样本](3.3.0.4850.md#text)已不同。来源：[旧 reference](../../skills/affinity-mcp/references/sdk-verified.md)及[脱敏证据摘要](evidence/2026-10-08.md#a-02) |
| `createInsertGlyph(..., CharGlyph.create(33))` | 构造失败：`expected GlyphHandle` | 只限定该路径，不否定普通文本写入。来源：[Skill](../../skills/affinity-mcp/SKILL.md) |
| 默认笔刷 | `VectorBrush.createDefault()` 抛错；未取得可用 RasterBrush 对象 | 已有 vector brush 是另一个已测入口。来源：[reference](../../skills/affinity-mcp/references/sdk-verified.md) |
| `ExportScale.createWithWidthHeight(600, 800)` | 读回为 Square、multiplier 600、size 800 | 不把这个工厂当作宽高设置配方；新构建未复验。来源：[Skill](../../skills/affinity-mcp/SKILL.md) |
| `FileSystemPromises.copyFile` | 返回 `NO_ENVIRONMENT`；其他指定异步读可用 | 按方法分别记录。来源：[reference](../../skills/affinity-mcp/references/sdk-verified.md) |
| `Document.generateImage` | 构造阶段 `PERMISSION_DENIED` | 一次拒绝不等于平台无 AI；不自动重试可能付费的操作。来源：[reference](../../skills/affinity-mcp/references/sdk-verified.md) |
| 现有文档插页、Boolean 全组合、复杂选区、更多导出选项 | 未找到可用入口或没有足够验证 | 保持原有区分，不合并成“全部不支持”。主题入口：[README](../../README.md#unsupported-or-unverified-features)；历史来源为上面的固定提交 |
