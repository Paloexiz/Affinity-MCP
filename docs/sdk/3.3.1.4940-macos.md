# Affinity 3.3.1.4940 MacOS SDK 能力样本

观察日期：2026-10-19、2026-10-20、2026-10-21。本页记录批量/预览、Margin/Bleed、光学对齐、文本流/关闭，以及SDK入口、基础对象、布尔/字符插入、文件与导出样本；不继承其他构建的完整能力目录。

## 身份与对象

应用自报 `Affinity 3.3.1.4940 MacOS (Oct  6 2026)`；此前各实验未取得独立SDK字段，2026-10-21入口补测读到 `Environment.sdkVersionStr="0.1"`，不回填此前记录。2026-10-19批量实验的运行插件为 `0.4.3`，安装副本与对应仓库代理hash一致；宿主精确版本未记录。该身份不扩展到后续其它实验。括号日期不解释为发布日期，也不使用后来的开发候选代填运行身份。[B-01](evidence/2026-10-19.md#b-01)、[F-01](evidence/2026-10-21-sdk-availability.md#f-01)

2026-10-19 样本为 800 × 600 document pixels、96 DPI、单 spread 的自建未保存文档。对象使用唯一合成标记，快照比较标记集合及六个变换矩阵分量；没有验证任意节点属性、混排文字、嵌套对象或生产工程。样本关闭后重新枚举确认移除。2026-10-20 的海报身份与范围单独记录于 [C-01](evidence/2026-10-20.md#c-01)，不把后来的样本补写为旧实验已经覆盖。

## 样本结果

| 用例 | 后置结果 | 状态与边界 |
| --- | --- | --- |
| 逐个插入或移动 3 个对象 | 3 次 undo 返回前态，3 次 redo 返回后态，再次 undo 返回前态 | 指定命令及对象样本通过；B-02 |
| 批量插入、共享选区移动、compound 移动 3 个对象 | 各 1 次 undo/redo/undo 匹配前后快照 | 指定样本通过；不是“一条脚本永远一次撤销”；B-02 |
| 移动 500 个目标，保留另 6 个标记 | 逐个命令需 500 次 undo；共享选区与 compound 各需 1 次；redo 和再次 undo 均匹配快照 | 六个非目标标记也在比较中；未覆盖历史裁剪、自动合并或其他属性；B-03 |
| 在同一工具入口分开/合并简单编辑步骤 | 减少工具调用后，目标矩阵、预览图像内容及恢复快照符合目标 | 是预设工作流对照，不是自主 Agent 指引前后验收；B-04 |
| 500 个矩形逐个/批量插入 | 合成标记与矩阵快照、渲染内容一致，撤销后匹配原始对象快照 | SDK 命令效率与整体耗时需分别判断；B-04 |
| 从稳定的 1000 项集合读取 500 项 | 重复 `.at()` 与一次转数组再索引得到相同结果序列 | 指定查询样本通过，不支持跨修改复用成员或属性快照；B-04 |
| 500 矩形插入，逐个/批量命令与全量/摘要回传组合 | 全量检查及完整预览相同；两种回传模式下批量路径的总体中位耗时均更高 | 小样本且有明显波动；指定后态样本通过，性能验收未通过，不能作为创建提速的依据；B-05 |
| 同向移动 500 目标，另保留 6 标记 | 五组配对的工具耗时合计有四组更快、一组较慢；另三组连续计时均较快且中位数下降；全部后态、图像和撤销恢复检查通过 | 只支持该预设工作负载的有限性能结论，不推广至插入或其他工程；B-06 |
| 每轮独立文档，500 矩形逐个/批量插入 | 同一宿主入口三组配对均为批量路径的创建到完整预览较短，中位耗时下降；全量标记、矩阵、逐轮图像和撤销恢复均核对 | 探索性三组；计时内保留导入与身份检查，不含夹具建立、清理或 Agent 决策；扩大样本未确认稳定收益，见 B-08；B-07 |
| 扩大至 12 组独立文档创建配对 | 24 个样本的全量状态、完整图像与撤销清理均匹配；批量九组较快、三组较慢，先后顺序分层方向不同 | 旧三组未并入；保留所有长等待，未确认稳定创建提速，不以总体中位数代替分层和区间判断；B-08 |
| 同一 batch500，独立 render 与单脚本 PNG 回传对照 | 12 对、24 个独立文档的标记/六矩阵/选区、完整图像和一次撤销恢复均通过；两个顺序层均支持缩短创建到图像交付时间 | 同一 Codex/functions 宿主上下文，中位 4325.5 → 2585ms；仅支持受限预览路径，不证明其他连接上下文的可用性、批量插入本身或自主 Agent 决策更快；B-09 |

来源：[脱敏技术证据 B-02～B-09](evidence/2026-10-19.md)。使用策略见随包 [执行效率与撤销边界](../../skills/affinity-mcp/references/scripting-pitfalls.md#execution-efficiency)及[单调用预览边界](../../skills/affinity-mcp/references/scripting-pitfalls.md#single-call-preview)。

## 海报预览补测

2026-10-20 的单画板合成海报为 600 × 800 px、96 DPI，含四个可编辑文字块、一个实际嵌入位图和原生 Margin/Bleed。实际 Margin getter、启用状态与有效安全框读回通过；Bleed 四边值/启用状态由文档设置界面观察，SDK 另核对 620 × 824 的实际外缘几何，未取得活动文档 Bleed 属性 getter 路径。[C-01](evidence/2026-10-20.md#c-01)

| 用例 | 结果与边界 |
| --- | --- |
| 默认 spread/selection render 与 PNG/CurrentSpread | 漏掉外侧 Bleed；裁切区十二对中位 5080.5 → 2946.5 ms，12/12 较快，但不能作为完整出血预览通过；[C-02](evidence/2026-10-20.md#c-02) |
| 完整选区 PNG | 只有已核对的全内容选区及恰好覆盖 native Bleed 的背景，`createForSelection` 才在此样本覆盖 620 × 824；`createForSelectionArea` 不等价，跨范围 PNG 也不保证逐像素相同；[C-03](evidence/2026-10-20.md#c-03) |
| 同一完整选区 PNG，分开两调用/合成一调用 | 另一组十二对均通过全文/样式/位图/几何/选区、全部 510,880 像素及四边标记检查；中位 4714.5 → 2638 ms，降幅 44.04%，两顺序层均支持收益；从空白文档请求计至完整图像 handoff，非前端 paint 确认；[C-04](evidence/2026-10-20.md#c-04) |
| 独立标线检查图 | 从同样本完整 PNG 派生，显示完整 Bleed、Trim 与有效 Margin；保留原图字节，去标线渲染的图像区逐像素一致。这是本地后处理，不是新增 SDK 能力，未纳入上述性能计时；[C-05](evidence/2026-10-20.md#c-05) |
| 标题越界与透明出血缺口负例 | 实际标题越过 Margin 左边约12.61px，底部右半310 × 14px透明；实心底图两名读者漏报出血缺口，棋盘底图的两名新读者均发现两项问题，对照无这两项误报；六对带线总耗时中位3611.5ms，本地标线加渲染64.25ms，不作加线提速或普遍检出率宣称；[C-06](evidence/2026-10-20.md#c-06) |

两组独立统计；实际撤销均恢复配置不变的空画板及选区，随后关闭指定样本。它们不验证任意选区、剪裁层次、真实照片或印前色彩/尺寸，也不证明新 Skill 的自主决策耗时。

## 光学对齐与中文标点补测

2026-10-20 的两批隔离单行样本分别比较 None/Manual/Font，以及 None/Manual/UI Custom；每批 84 个 Art/Frame 对象、两种字体、24px/96DPI。Custom 是界面编辑规则后的 Manual 标签，不是新增枚举。该次代理实际加载身份及宿主精确版本未单独记录。[D-01](evidence/2026-10-20-optical-alignment.md#d-01)

| 操作/目标 | 结果与边界 |
| --- | --- |
| SDK 光学模式读写 | `GlyphAtts.opticalAlignmentType`、`StoryDelta.createOpticalAlignmentType` 的 None=0/Manual=1/Font=2 写读与实际 Art/Frame 渲染通过；不是仅凭 hints 搜索判断接口存在；[D-02](evidence/2026-10-20-optical-alignment.md#d-02) |
| 自定义字符与悬挂百分比 | 已查 wrapper、相关原生模块/原型与官方符号索引未找到规则表入口；属于已查 SDK 入口缺口，不是“MCP 协议不支持光学对齐”；[D-02](evidence/2026-10-20-optical-alignment.md#d-02) |
| 未自定义 Manual / Font | 本次 Manual 改善引号，但未覆盖 `「」（）。，`；Font 效果随字体/操作变化；[D-03](evidence/2026-10-20-optical-alignment.md#d-03) |

## 文本框链接、取消链接与异步关闭补测

2026-10-21 使用两个独立的 640 × 480px、96 DPI、单 spread、未保存合成文档，每个含两个框架文本。该次运行插件为 `0.5.3`，应用 `buildVersion=1`；宿主精确版本和独立 SDK 版本未取得。身份、原文、runs 与比较范围见 [E-01](evidence/2026-10-21-text-flow-and-close.md#e-01)，不沿用其他实验的身份。

| 操作/目标 | 后置结果与边界 |
| --- | --- |
| 链接到空目标框 | 57 字符源 Story 接排到第二框，目标 `textBegin=39`；24/16/20px 字号、字体和段落格式保持，框几何、变换与文字缩放不变；[E-02](evidence/2026-10-21-text-flow-and-close.md#e-02) |
| 链接到已有格式的目标框 | 源全文 + 段落分隔 + 11 字符目标原文合为 69 字符，目标原文保持 18px 半粗体与居中；[E-03](evidence/2026-10-21-text-flow-and-close.md#e-03) |
| 对目标框取消链接 | 两组目标框均变空，全部 57/69 字符及已比较格式留在源框 Story，源框溢出；不会按可见文字拆分，也不会恢复链接前各自原文；E-02、E-03 |
| 链接/取消链接的撤销重做 | 各自单步 undo/redo 及再次 undo 匹配留存快照；两组恢复后的链接 PNG 与各自基线字节相同；仅证明这些命令与历史；[E-04](evidence/2026-10-21-text-flow-and-close.md#e-04) |
| `closeAsync(callback)` / `document.promises.close()` | 各直接关闭一个 `isDirty=true`、`needsSaving=true` 样本，未保存或进行提示交互，未保存内容被丢弃；回调无错误/Promise 完成且重新枚举目标消失；不证明失败路径或关闭后恢复；[E-05](evidence/2026-10-21-text-flow-and-close.md#e-05) |

以上指定用例样本通过。取消链接的文本去向与关闭的丢弃后果必须在操作前明确；一般关闭请求不等于丢弃用户工作授权。随包[链接文本流指引](../../skills/affinity-mcp/references/sdk-verified.md#linked-text-flow)及[异步关闭指引](../../skills/affinity-mcp/references/scripting-pitfalls.md#async-close)不依赖开发证据。未测三框/跨 spread 链、源/中间框取消链接、任意格式属性或链接范围的新格式写入、保存重开及已有磁盘文件的未保存修改；该补测不扩展光学对齐的链接流结论。

## SDK 入口、基础对象与文件补测

2026-10-21按官方符号索引、应用内wrappers与native原型链核对全量入口；行为补测分别使用脱离文档的值对象和明确授权的自建样本。调用入口插件0.5.3，应用buildVersion=1，SDK自报0.1；宿主精确版本未记录。[F-01～F-07](evidence/2026-10-21-sdk-availability.md)

| 操作/目标 | 后置结果与边界 |
| --- | --- |
| 全量入口 | 455个API对象/20个模块，4,332个文档原生方法中4,260个有直接函数入口、72个缺失；继承路径另计，入口不是功能通过；[F-01](evidence/2026-10-21-sdk-availability.md#f-01) |
| 基础对象、布尔、字符 | 值/克隆类型及RGBA8指定像素通过；四种矩形布尔的几何/像素/保护节点与恢复通过；普通字符AB→A!B保持已比较格式/框/scale；[F-02～F-04](evidence/2026-10-21-sdk-availability.md#f-02) |
| 尺寸与笔刷 | 单参数尺寸对象读回通过，两个双参数工厂有语义反例；默认PathBrush/RasterBrush工厂为wrapper占位错误，旧VectorBrush模块加载失败；[F-05](evidence/2026-10-21-sdk-availability.md#f-05) |
| 文件、导出与保存 | UTF-8写读、同步复制、五种同步导出、异步PNG/CurrentSpread及saveAs/重开通过；异步复制仍NO_ENVIRONMENT；指定预设的无出血矩形样本，不升级其它区域/格式/保存模式；[F-06](evidence/2026-10-21-sdk-availability.md#f-06) |

本组58例中52例达到限定目标、6例未达到；成功调用路径关联115个文档方法，不是逐方法完整语义认证。另有4,142个有入口方法未完成功能验收，72个入口缺口、两个原生尺寸反例和一个异步复制失败分别保留。证据页保存脱敏后置摘要，没有附原始截图/文件。随包配方见[能力边界](../../skills/affinity-mcp/references/sdk-verified.md)及[文件验收](../../skills/affinity-mcp/references/sdk-verified.md#verified-file-and-export-workflow)。

## 不应推广的结论

历史位置差值不能单独证明恢复；本样本中它与已核对的实际撤销步数一致，不解释其他历史状态的失败。相反变换也不是通用回滚方案。

本页不证明所有批处理的请求到预览耗时更短，也不证明已安装宿主采用了修改后的Skill。未验证Windows/Linux、复杂文本与滤镜、长期内存、任意撤销历史、业务文档关闭，以及指定样本之外的保存/导出场景。海报仍需读取目标工程的原生设置；无出血导出和完整选区导出的样本均不替代Bleed属性读取或印前验收。
