# 2026-10-08 脱敏 SDK 证据摘要

本页汇总 2026-10-08 的 SDK 样本结果和只读探针证据，结论仅适用于下述条件。匿名证据 ID 只用于在本页和构建记录中稳定引用，不映射到会话、文件或用户身份。

## 适用条件

- Affinity：`3.3.0.4850 Win32`；观察日期：2026-10-08。
- 仓库插件清单：`0.1.10`；独立 SDK 版本：未取得。
- 主样本是无业务内容的隔离、未保存文档，640 × 480 document pixels、96 DPI、1 页，包含普通文本、混排文本和小尺寸文本框。
- 本页不保存原始脚本、原始回包、运行时对象标识、会话标识、本机路径或个人工作内容。没有图片像素时，视觉结论只保留为执行时观察，不能由本页重看。

## 证据

### A-01：应用身份、入口和 Collection

只读探针确认了该构建的应用版本和平台。`DocumentApi.getDocumentProperties` 在所查入口为 `undefined`；`app.userDesktopPath` 有 getter，但应用模块顶层同名导出没有可用值；`UnitType`、`DocumentCommand` 不在脚本全局作用域。`Collection.of(1, 2)[0]` 为 `undefined`，`.first` 与 `.at(0)` 返回首项。

这些结果只约束所查入口和对象，不证明同名功能在所有 native 模块或未来构建中不存在。

<a id="a-02"></a>
### A-02：文本替换和溢出

当前 `Node.setText` wrapper 使用 `TextSelection.create(this.storyRange)`。普通文本完整替换在隔离样本上读回通过；20px/12px 混排文本替换后合并成单一 20px run，因此普通替换不构成保留混排格式的通用配方。

`canHideOverflow` 在所查 wrapper 中是 getter。小尺寸文本框的 Story 字符仍完整存在，已有执行观察显示文字溢出框外；这不足以证明隐藏状态已经打开，也不能据此推断永久丢字。改字后的行数、runs、框尺寸和可见范围仍需逐项验收。

### A-03：同步关闭

对隔离未保存样本调用同步 `Document.close()` 后重新枚举文档，目标样本消失。该结果只覆盖同步路径、该构建、该类隔离样本和该后置检查；`closeAsync`、promises close、带未保存业务文档及其他平台仍未验证。

### A-04：水平与垂直 Align

当前 wrapper 和已查 native 原型中存在水平段落 Align 相关入口，包括 `ParagraphAtts.alignXType`、`StoryDelta.createAlignX` 和 `DocumentCommand.createFormatText`；只读检查得到 9 个水平枚举成员。当前检查范围内没有找到框内垂直 Align 的对应读写入口。

这里的“未找到入口”是检查范围内的能力缺口，不是对整个应用功能的永久否定。移动文本框、改变框尺寸或做视觉居中也不等于设置原生垂直 Align。

### A-05：错误和代理边界

某些负向探针会在结果文本中包含 `Error:` 或返回 `isError=true`；不能只依据一个状态字段判断 SDK 操作是否完成。代理的连接、SSE endpoint、POST、响应等待和迟到响应分别有独立边界；超时后必须先读回目标状态，不得自动重放可能已经提交的脚本。[代理实现](../../../scripts/affinity-mcp-proxy.mjs)和[代理回归测试](../../../scripts/affinity-mcp-proxy.test.mjs)是传输行为的主要来源。

## 证据等级和限制

“样本通过”只表示指定构建、平台、对象和后置状态满足该用例；“只读确认”只表示入口或元数据存在；“未验证”不等于“不支持”。应用构建差异与插件版本差异分别记录，不能把单个样本推广为所有对象、文档状态或平台的保证。

通用入口和历史能力边界见[SDK 版本索引](../README.md)、[验证方法](../verification.md)以及随包的 [SDK reference](../../../skills/affinity-mcp/references/sdk-verified.md)。文本框和排版概念应同时参考 Affinity 的[文本框帮助](https://www.affinity.studio/help/text-fitting-frame-text)与[Text Frame 面板帮助](https://www.affinity.studio/help/panels-text-frame-panel)；官方 UI 说明不能单独证明 SDK 写入入口。
